Findings

This standalone HTML file owns its own cover, headings, typography, and styling. The docs-shell doesn't wrap it: clicking the topnav button for this doc navigates the browser directly to example-report.html. A rendered Flint chart, an exported dashboard, or a static tabular report would live here in the same shape.

In a real report this is where the Flint-rendered SVG or PNG would sit, or an inline <svg> block, or an interactive chart mount point.

Why bypass the shell

The shell is a viewer for source-of-truth Markdown. Pre-built reports already are the source of truth: they carry their own cover page, hero copy, and print styles, and they often need full-width layout that a sidebar TOC would fight. Linking directly, rather than injecting into #content, keeps that presentation intact.

Getting back to the shell

Use the browser back button, or the brand link (top-left) on the shell's own topnav. Because the shell used location.replace() when redirecting to this file, the back button skips the shell hop and returns to whatever you were doing before.
